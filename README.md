Gimme That Grub

Uses a potentiometer to move a standard servo. CircuitPython, CircuitPlayground (BLuefruit or Express) and a standard micro-servo (Tower SG92R is what I use in class).
- CircuitPlayground (Bluefruit or Express)
- Micro Servo (Tower SG92R or compatible)
- Potentiometer: I use STEMMA Wired Potentiometer Breakout Board - 10K ohm Linear - STEMMA Wired Potentiometer Breakout Board - 10K ohm Linear
- To connect the above breakout to the CircuitPlayground with alligator clips: JST PH 2mm 3-pin Plug to Color Coded Alligator Clips Cable - https://www.adafruit.com/product/4030
- 3 alligator to pin wires (to connect servo to CPB)

 The enclosed .pdf is used in the demo below.
